## Выгрузка полного индекса

Скрипт: `scripts/scrape_rules.py [out.json]` — обходит разделы, отдаёт
`[{section, title, url}]`, ~679 записей, URL раскодирован.

Как это устроено (если сайт поменяется): страницы разделов отдают ссылки в
percent-encoded виде, текст ссылки стоит сразу после `href`:

```python
import re, urllib.parse
links = re.findall(r'href="(/[^"]*)"[^>]*>([^<]{1,200})</a>', page)
# отфильтровать ссылки, начинающиеся с раздела после unquote();
# в отчёт отдавать url раскодированным: BASE + urllib.parse.unquote(href)
```

Заходить на раздел через `curl -sS -L`. Индекс годится как `references/` скилла:
тогда URL в отчёте выбирается из существующих, а не сочиняется. В MCP его
заворачивать не нужно — это статический JSON.
